# Decisions

This directory holds the decisions that shape the project, each with the
reasoning that produced it and the alternatives that were rejected. They are
written before the code that depends on them, they are numbered, and a landed
record is never rewritten: one that turns out to be wrong is superseded by a
later record that names it, and the old one stays with a pointer forward. Record
0001 is the format and the rules; the rest are the decisions themselves. No list
of them appears here, because a list in a document drifts against the directory
it describes, and the directory is one `ls` away.
